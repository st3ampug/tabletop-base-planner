Terrain on this layout

Turn on Edit terrain to drag pieces around. An area carries its walls with it; a wall moves on its own. Tap a piece to rename, turn or remove it. Each layout keeps its own changes.

Collision rules

Each terrain piece has its own rule. By default terrain areas (pale, dashed) can be entered and walls, barriers, pipes and generators (dark) block. Tap any piece on the board to switch it.

Unit coherency

" of 2 others in units of+

Defaults are the 10th-edition values: within 2" of one other model, two others for units of 7 or more. Set them to your 11th-edition card. Distances are measured base edge to base edge.

Boards

Each board keeps its own layout, armies and positions, and saves itself in this browser.

Save and load

To move a board to another device, copy the text below and load it there. A map file loads the same way. The copied text also describes the table (zones, objective centres, terrain and walls in mm) for anyone analysing it.

Layouts: 40kdc-data by Alpaca Software and the 40kdc community, CC BY 4.0, imported there from Battlemaster. Changed here: outlines simplified, board turned to portrait with the attacker at the top, one misplaced generator corrected.

Map file format 
{
 "name": "My layout",
 "units": "in",          // or "mm"
 "width": 44, "height": 60,
 "zones": [{"owner":"red","poly":[[0,0],[44,0],[44,18],[0,18]]}],
 "terrain": [{
   "name": "Ruin", "kind": "area",   // or "scenery" for walls
   "objective": "home",   // home | round | diamond, optional
   "collision": "allow",  // or "block"
   "poly": [[19.5,45],[31,45],[31,52],[19.5,52]]
 }]
}
